# DDoS Attack Incident Analysis

## Objective

Analyze a Distributed Denial of Service (DDoS) attack and document the incident response process using the NIST Cybersecurity Framework (CSF).

## Scenario

A company experienced a network outage caused by a flood of ICMP packets originating from multiple sources. The attack disrupted critical network services and required immediate response from the cybersecurity team.

## Framework Used

- Identify
- Protect
- Detect
- Respond
- Recover

## Skills Demonstrated

- Security Incident Analysis
- Network Security
- DDoS Mitigation
- Log Analysis
- NIST Cybersecurity Framework

## Key Takeaways

This project demonstrates how cybersecurity teams analyze, respond to, and recover from DDoS attacks while following industry-standard security frameworks.
